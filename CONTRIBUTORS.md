# Contributors

Everyone who has helped build Glassbeetle.

This list is not limited to people who wrote code. Documentation, tests,
reviews, a reproducible bug report, infrastructure, design, or asking the
question that turned into a written-down convention — all of it counts, and all
of it belongs here.

---

## Maintainers

Maintainers look after the long-term direction of the project. They review pull
requests, triage issues, and decide the conventions that
[`docs/`](docs/) records.

- [@nathanschmid08](https://github.com/nathanschmid08) — Founder & Core Maintainer

If you are not sure who to ask about something, ask anyway — open an issue with
the `question` label.

## Want to be listed here?

Contributions are welcome, and you do not need permission to start.

- [Good first issues](https://github.com/Open-Glassbeetle/glassbeetle/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
  — scoped so you can finish one without reading the whole codebase
- [All open issues](https://github.com/Open-Glassbeetle/glassbeetle/issues)
- [CONTRIBUTING.md](CONTRIBUTING.md) — the short path from a clone to a merged
  pull request

Once your pull request is merged you will be added here. If you were missed,
that is an oversight rather than a judgement — say so in the thread and it gets
fixed.

## For maintainers: adding someone

Comment on any issue or pull request, and the bot opens a pull request against
this file:

```
@all-contributors please add @username for doc, test
```

The types come from the
[emoji key](https://allcontributors.org/docs/en/emoji-key) — `code`, `doc`,
`test`, `bug`, `review`, `ideas`, `infra`, `design`, `a11y` and others.

Prefer naming what someone actually did over defaulting to `code`: being
credited for the documentation you wrote reads better than being credited for
code you did not.

`.all-contributorsrc` is the source of truth. The table above is generated from
it, so edit the config rather than the table — and if you do edit the table by
hand, the bot will overwrite it on the next run.
